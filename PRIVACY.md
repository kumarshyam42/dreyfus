# Privacy Policy

*Last updated: 15 October 2026*

Dreyfus Method is a Claude plugin made of a single instruction file (`skills/dreyfus/SKILL.md`). The file tells Claude how to teach. It contains no code, no scripts and no connections to outside services.

## What the plugin collects

Nothing. The plugin does not collect, store or share any personal data, and it does not send data anywhere. The author never receives your conversations or any information about you.

## Your conversations with Claude

When the plugin is active, your conversations are processed by Claude in the same way as any other conversation. Anthropic handles that data under its own [privacy policy](https://www.anthropic.com/legal/privacy). This plugin adds no extra processing and no extra destinations.

## Changes

If a future version changes any of the above, this page will be updated before that version is released.

## Contact

For questions about this policy, open an issue at [github.com/kumarshyam42/dreyfus/issues](https://github.com/kumarshyam42/dreyfus/issues).
